Criterio de uso

PIF-SST clasifica hallazgos respaldados por evidencia. No sustituye una metodología de investigación de incidentes y no convierte la taxonomía en una lista de chequeo para asignar causas.

PIF-SST preventivo

Análisis de condiciones antes del trabajo

Usa la taxonomía PIF como lente para documentar condiciones que pueden favorecer o dificultar el desempeño antes de una tarea crítica, durante una revisión previa o en una gestión del cambio.

Aplicación preventiva ampliada

EI 3646 fue desarrollado para clasificar hallazgos de investigaciones de incidentes. Este módulo utiliza el concepto PIF y la misma taxonomía como apoyo preventivo. No es un uso formalmente validado por EI 3646 y no sustituye la evaluación de riesgos, permisos de trabajo, procedimientos ni la decisión profesional sobre si una tarea puede ejecutarse.
